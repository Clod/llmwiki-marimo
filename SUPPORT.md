# Support

Thanks for using llmwiki-marimo! Here's where to go depending on what you need.

## 📖 Documentation first

Most questions are answered in:

- The [README](README.md) — setup, quick start, LLM providers, limitations
- The [programmer manual](docs/programmer_manual.md) — architecture and internals
- The [SQLite data dictionary](docs/sqlite_data_dictionary.md) — what ends up on disk

## ❓ Questions and usage help

Open a [GitHub issue](https://github.com/Clod/llmwiki-marimo/issues/new) describing
what you're trying to do, what you expected, and what happened instead. Plain
questions are welcome — you don't need to force them into a bug report.

## 🐛 Bugs and feature requests

Use the [issue templates](https://github.com/Clod/llmwiki-marimo/issues/new/choose).
Please check [Limitations & non-goals](README.md#limitations--non-goals) before
requesting a feature — some things are intentionally out of scope.

## 🔒 Security issues

**Do not open a public issue.** Report vulnerabilities privately via a
[GitHub security advisory](https://github.com/Clod/llmwiki-marimo/security/advisories/new) —
see [SECURITY.md](SECURITY.md).
